零语表情包助手 · 离线联调预览

不连真实站点，用桩件（stub）跑通「搜索 → 下载 → 上传 → 发送」全链路。默认走官方通道（把图交给 composer 的 file input，站点自己上传）；设置里切成「只用直连链路」才由脚本自己 presign → PUT → bind → WebSocket。

怎么用 3 步

  1. 点下面模拟聊天区的 😊 按钮展开表情面板，切到第三个 梗图 栏。
  2. 输入任意关键词（如 哈哈）→ 搜索 → 点一张图选中 → 发送。
  3. 滚到本页下方看 请求日志：默认应出现 [官方上传器] 前缀的条目（站点的链路）；在设置里切成「只用直连链路」后，才会出现 POST …/api/upload/presign 这类脚本自己发的请求。
